# 星际守卫

小朋友的第一个游戏作品

一个浏览器第一人称射击小游戏：从简单的枪战想法开始，逐步加入大地图、立体方块人物、行走动画、滑铲和多种武器。

**[在线试玩](https://www.shuanghai.shop/orbit-defense/)**

## 如何运行

下载仓库，用电脑浏览器打开 `index.html` 即可，无需安装依赖。手机也可通过在线地址游玩。

## 游戏内容

- 48 × 42 竞技场、掩体、绕行路线和小地图。
- 立体方块人物、行走动画，以及玩家和敌人的滑铲。
- 骨头步枪、冲锋枪、霰弹枪、机枪、像素狙击枪，全部无限弹药。
- 三倍狙击镜、敌人血条、每回合三分钟倒计时。
- 枪声、脚步声和设备支持时的中文语音。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD | 移动 |
| 鼠标 | 转动视角 |
| 鼠标左键 | 射击 |
| 1–5 | 切换武器 |
| 鼠标右键 / Q | 狙击枪开关瞄准镜 |
| 空格 | 跳跃 |
| Shift | 滑铲 |
| P | 暂停 / 继续 |
| Esc | 释放鼠标 |

手机可使用页面下方的操作按钮。

## 关于作品

由小朋友提出创意，与 AI 协作逐步制作。部分视觉创意参考 Roblox、Rivals 和方块游戏风格；本项目为独立练习作品，非官方游戏。

源码集中在 `index.html` 中，使用 HTML、CSS、JavaScript 和 Canvas，可直接阅读和修改。
