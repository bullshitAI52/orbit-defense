# 星际守卫｜曾子城小朋友的第一个游戏作品

**作者：曾子城（五年级）**  
**创作日期：2026 年 11 月 15 日**  
**创作方式：使用 ChatGPT 编写，由曾子城提出创意并逐步完善游戏。**

这是曾子城小朋友的第一个游戏作品，记录五年级时把自己的游戏想法变成可以玩的作品的过程。希望多年以后，曾子城还能找到这份属于自己的创作纪念。

一个浏览器第一人称射击小游戏：从简单的枪战想法开始，逐步加入大地图、立体方块人物、行走动画、滑铲和多种武器。

**[在线试玩](https://www.shuanghai.shop/orbit-defense/)**

## 如何运行

下载仓库，用电脑浏览器打开 `index.html` 即可，无需安装依赖。手机也可通过在线地址游玩。

## 游戏内容

- 101 张可选竞技场地图：在原地图基础上新增 100 种掩体布局，开局玩家与 AI 对手各选一张，双方地图各有 50% 概率成为本局地图。
- 开局可选择人机对决或在线真人 1 对 1；真人模式输入相同房间码即可连线，服务器会让双方所选地图各有 50% 概率入选。
- 48 × 42 战场、掩体、绕行路线、选图预览和小地图。
- 立体方块人物、行走动画，以及玩家和敌人的滑铲。
- 骨头步枪、冲锋枪、霰弹枪、机枪、像素狙击枪，全部无限弹药。
- 三倍狙击镜、敌人血条、每回合三分钟倒计时。
- 枪声、脚步声和设备支持时的中文语音。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD | 移动 |
| 鼠标 | 转动视角 |
| 鼠标左键 | 射击 |
| 1–5 | 切换武器 |
| 鼠标右键 / Q | 狙击枪开关瞄准镜 |
| 空格 | 跳跃 |
| Shift | 滑铲 |
| P | 暂停 / 继续 |
| Esc | 释放鼠标 |

手机可使用页面下方的操作按钮。开局先选地图：玩家地图可自行挑选，对手默认随机选图，也可以点击“让对手重新选图”，随后抛硬币决定最终地图。

## 关于作品

由曾子城小朋友提出创意，使用 ChatGPT 协作编写并逐步制作。部分视觉创意参考 Roblox、Rivals 和方块游戏风格；本项目为独立练习作品，非官方游戏。

源码集中在 `index.html` 中，使用 HTML、CSS、JavaScript 和 Canvas。在线真人对局另需运行 `server/match-server.js`，依赖安装说明见 `server/package.json`。
